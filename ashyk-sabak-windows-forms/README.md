# Ашық сабақ — «Алғашқы Windows қосымшаларын құру және бағдарлама интерфейсі»

Интерактивная веб-презентация для открытого урока на **45 минут** (редакция по второму варианту Word-документа).

| | |
|---|---|
| Колледж | «М. Өтебаев атындағы жоғары жаңа технологиялар колледжі» МКҚК |
| Преподаватель | Каюпова Т.Т. |
| Группа / курс | АЖ-03-24 · 3 курс |
| Среда | Microsoft Visual Studio · C# · Windows Forms |
| Язык презентации | казахский |

Это самостоятельный проект: с другими репозиториями (в том числе AZAT FINANCE) он не связан.

---

## 1. Быстрый запуск на компьютере колледжа (без Node.js)

1. Распакуйте `release/Ashyk-sabak-WinForms.zip` целиком.
2. Дважды щёлкните **`START.bat`**. Презентация откроется в Microsoft Edge на весь экран. Если Edge нет, откроется браузер по умолчанию.
   `OPEN-OFFLINE.bat` открывает её в браузере по умолчанию, в обычном окне.
3. Интернет не нужен. Он нужен только кнопкам, которые открывают Baamboozle, LearningApps и Genially.

Как это проверено: сборка — **один файл** `index.html`, в который встроены весь JS, CSS и шрифты (`vite-plugin-singlefile`). Он открывается двойным щелчком (`file://`), локальный сервер не нужен. Проверено в Chromium через `file://` с блокировкой всех сетевых запросов — подробнее в разделе 6.

### Видео ИИ (слайд «Адал азамат», этап «Ұйымдастыру кезеңі»)
На слайде «Адал азамат» каждая из 4 карточек ценностей открывает своё видео (по нажатию, крупным окном поверх слайда). Положите файлы:
- в готовой сборке — в `presentation/videos/`;
- в исходниках — в `public/videos/` (затем `npm run package`).

| Файл | Карточка |
|---|---|
| `adal-1.mp4` | Әділдік пен жауапкершілік |
| `adal-2.mp4` | Заң мен тәртіп |
| `adal-3.mp4` | Еңбекқорлық пен кәсібилік |
| `adal-4.mp4` | Бірлік пен ынтымақ |

Видео ИИ с объяснением темы — `topic-ai.mp4`: открывается кнопкой «Тақырып бойынша бейнеролик» на слайде «Енгізу және шығару сұқбаттық терезелері» (путь задаётся в `lessonInfo.topicVideo`).

Имена можно поменять в `src/config/lesson.config.ts` → `adalAzamat.videos`. Формат — MP4 (H.264 + AAC). Пока файла нет, в окне показывается подсказка, куда его положить. Окно закрывается кнопкой ✕, клавишей Esc или кликом мимо окна.

### Составы групп (слайд «Топқа бөлу»)
Две готовые группы: **1-ТОП — WriteLine** и **2-ТОП — ReadLine**.
- Имена вписываются прямо на слайде: маленький значок ✎ в правом верхнем углу карточки группы. В редакторе можно добавить ученика (поле + «Қосу» или Enter), вставить сразу список («Тізімді қою», по одному имени на строку), исправить имя, поменять порядок (↑ ↓) и удалить (🗑).
- Составы сохраняются в этом браузере (`localStorage`) и не стираются кнопкой «Барлығын тазалау».
- Кнопки «1-топты ашу» и «2-топты ашу» показывают пронумерованный список. До нажатия имена скрыты.
- Блок «Сәттілік дөңгелегі» открывает колесо https://wheelofnames.com/ru/kr4-w7r в большом окне (нужен интернет). Есть кнопка «Жаңа қойындыда ашу»; без интернета показывается сообщение. Ссылку можно поменять в панели T → «Сілтемелер».

### Фото преподавателя
Положите фото с именем `teacher.jpg`:
- в готовой сборке — в `presentation/images/teacher.jpg`;
- в исходниках — в `public/images/teacher.jpg` (затем `npm run package`).

Фото появится на титульном слайде автоматически. Пока файла нет, показывается заглушка «Оқытушының фотосы». Лучше всего подходит вертикальное фото 3:4.

## 2. Управление

| Клавиша / кнопка | Действие |
|---|---|
| `→` `←` `PageDown` `PageUp` | следующий / предыдущий слайд (подходит пульт-кликер) |
| `T` или ⚙ справа вверху | панель преподавателя |
| `F` или ⛶ | полноэкранный режим |
| `Esc` | закрыть панель |
| полоса внизу | переход к этапу по клику |

**Общий таймер урока** (справа вверху) запускается кнопкой «Сабақты бастау». Клик по нему ставит его на паузу и снова запускает.
**Таймеры этапов** запускаются кнопкой ▶ на слайде. Когда время выходит, звучит сигнал и показывается «Уақыт бітті +мм:сс». Слайд **не переключается** автоматически.

### Панель преподавателя (T)
- **Кезеңдер** — все 14 этапов и 22 слайда, быстрый переход.
- **Таймерлер** — длительность каждого этапа и проверка, что сумма равна 45.
- **Топтар** — названия команд и ручной ввод очков.
- **Сілтемелер** — ссылки Baamboozle / LearningApps / Genially.
- **Баптаулар** — показ ответов, звук, общий таймер, вариант домашнего задания, шкала оценивания, **«Барлығын тазалау»** (подготовка к новому уроку).

Состояние сохраняется в браузере (`localStorage`): очки, ответы теста, открытые карточки, введённые данные. Можно свободно возвращаться к прошлым слайдам. Сброс перед новым уроком сохраняет ссылки, длительности и названия команд.

## 4. Что взято из Word, а что предложено (нужно проверить)

Источник — «Ашық сабақ новый.docx» (вторая редакция на 45 минут). Все тексты собраны в **`src/config/lesson.config.ts`** с пометками `[WORD]`, `[ТЗ]` и `[ПРЕДЛ.]`.

**Расхождения и решения:**
1. **Курс.** В Word указан 2-й курс, в презентации — 3-й (по ТЗ).
2. **Оценивание.** В документе «Студенттің бағалау парағы» — это **картинка-карточка «Ученический банк»** с полями «Балл» и «ФИО». **Таблицы критериев на 100 баллов в полученном файле нет.** Поэтому:
   - по умолчанию используется исходный вариант «Оқушы банкі»: имя и баллы студента;
   - отдельно предложена шкала Windows Forms на 100 баллов (`assessment.proposed`). Она включается только после того, как преподаватель отметит подтверждение в панели (T → Баптаулар).
   - Если у вас есть своя таблица на 100 баллов, впишите её критерии в `assessment.original.criteria`, и экран покажет её.
3. **Домашнее задание.** Исходные задания из Word сохранены дословно, хотя часть из них (сөздік, set/frozenset) относится к другой теме и к терминологии Python. Вариант по теме урока помечен «Ұсынылған нұсқа» и показывается, только если выбрать его в панели. По умолчанию показан вариант из Word.
4. **Практика (вторая редакция Word).** Прежние практические работы №1 и №2 заменены заданиями из нового документа:
   - форма «Қосу» с кодом `Convert.ToDouble` и `textBox3.ReadOnly = True`. Список компонентов в Word не приведён, поэтому состав формы и критерии — предложение, на слайде это помечено;
   - «Қатені тап» с ЖИ-помощником: 1-топ и 2-топ, коды и вопросы взяты из документа. Ответы составлены разработчиком и скрыты до нажатия «Жауабын көрсету»;
   - задание 2-топа «Хабарлама шығару» и подтверждение закрытия формы.
5. **Ссылки (вторая редакция Word):** Baamboozle — `https://www.baamboozle.com/game/4937714`, Genially — `https://view.genially.com/6adb30353d3e01e6f53986d3`.
11. **Сергіту сәті** — мини-флешмоб «Бағдарламашының көңіл күйі»: 5 ситуаций из документа и иллюстрация из него же.
12. **Оценивание:** добавлено правило из документа «Топтың басшысы топтағы студенттерді бағалау парағына бағалап отырады».
13. **Титульный слайд:** длительность урока убрана по просьбе преподавателя.
6. **Мини-тест.** Вопросы — из «Бақылау сұрақтары» Word и ТЗ, всего 11. Варианты ответов и пояснения составлены разработчиком.
7. **Visual Studio.** Схемы создания проекта и интерфейса повторяют **Visual C# 2010 с русским интерфейсом**, как в документе. На слайде отдельно описан путь в VS 2022.
8. **Пример №2 (сумма).** Код из Word (`double.Parse`) показан без изменений. В отдельном окне «Қате енгізу болса?» объяснено, что при пустом вводе будет `FormatException`, и предложен вариант с `double.TryParse`, совместимый с C# 4 / VS 2010.
9. **Написание «сұқбаттық»** сохранено, как в документе и в ТЗ.
10. **Логотипы приложений** на слайде «Топқа бөлу» не используются, только названия и цвета.

**Демонстрации Windows Forms** — это имитация в браузере (React). Каждое демо-окно подписано «Браузердегі демонстрация — нақты C# бағдарламасы емес». Код C# рядом — настоящий и корректный код Windows Forms из документа.

## 5. Визуальный стиль

Светлая, яркая EdTech-стилистика: белый и светло-голубой фон, синий как основной цвет, фиолетовый для C# и Visual Studio, бирюзовый для интерактивных блоков, оранжевый и жёлтый для игровых заданий, коралловый для акцентов. Тёмный фон есть только в окнах редактора C# — для подсветки синтаксиса.

- У каждого этапа своя цветовая тема и свой тип фона (`STAGE_THEME` в `src/components/brand.tsx`): мягкие пятна, геометрия, сетка, лучи, волны, фоновые символы кода.
- Векторные стилизованные логотипы C#, Visual Studio и Windows, иллюстрация компьютера с формой, плавающие фрагменты кода — без внешних картинок.
- Индивидуальные экраны:
  - титульный — арка для фото с цветными слоями;
  - Baamboozle — игровое табло «VS»;
  - разноцветный пазл с «салютом» при раскрытии темы;
  - светлые макеты Windows и VS 2010;
  - крупные цветные кнопки в примере №1;
  - практика в окне «рабочей области» IDE;
  - тест с цветными плитками ответов;
  - сундук на фоне лучей;
  - финал с конфетти.
- Переходы между слайдами чередуются: сдвиг, приближение, подъём. Анимации спокойные, бесконечно мигающих элементов нет.

## 6. Разработка

Требуется Node.js 20+.

```bash
npm install          # зависимости
npm run dev          # режим разработки: http://localhost:5173
npm run build        # сборка в dist/index.html (один файл) + dist/images
npm run package      # сборка + release/Ashyk-sabak-WinForms (+ .zip)
```

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Motion, Lucide React, Zustand. Шрифты Inter и JetBrains Mono (с казахскими буквами) встроены локально через `@fontsource`.

Структура:
```
src/config/lesson.config.ts   ← ВСЕ тексты, имена, ссылки, таймеры, оценивание, ДЗ
src/slides/                   ← по файлу на слайд или группу слайдов; порядок в slides/index.ts
src/components/               ← окно Windows, диалог MessageBox, таймер, панель преподавателя
src/store/useLesson.ts        ← состояние и его сохранение в localStorage
public/images/                ← teacher.jpg (добавить), doc/ — рисунки 1–7 из Word
scripts/package.mjs           ← сборка папки для Windows и ZIP
```

Сцена — фиксированный холст 1920×1080, который масштабируется под экран с сохранением 16:9. Поэтому на 1366×768 и на интерактивной панели ничего не обрезается и не нужна прокрутка.

## 7. Что проверено

Проверка в Chromium (Playwright), через `file://`, на собранном `dist/index.html`:
- все 22 слайда при **1920×1080** и **1366×768**: ничего не выходит за сцену и не требует прокрутки; сцена также проверена на 1600×900 и 1280×1024 (4:3 — с полосами сверху и снизу);
- автотест взаимодействий: **55 из 55 проверок пройдено** (плюс 17 отдельных проверок слайда «Топқа бөлу»), ошибок JavaScript нет. Проверялись:
  - заглушка фото, кнопка «Сабақты бастау» и запуск общего таймера;
  - карточки команд и «Бір-бірімізге сәттілік тілейік!»;
  - очки команд, таймер Baamboozle и открытие внешней ссылки;
  - пазл: тема скрыта → все части → вопрос → «Тақырыпты ашу»;
  - сохранение состояния при возврате назад;
  - 6 шагов создания проекта, подсказки по интерфейсу VS и файлам;
  - смена цвета формы (DarkBlue / Red / Yellow — проверены точные RGB);
  - сумма: 7+18=25, 2,5+0,1=2,6, пустой и ошибочный ввод → предупреждение, «Тазалау», «Жабу» → форма закрыта внутри слайда → перезапуск;
  - MessageBox: Yes → кнопка красная; FormClosing: No → форма остаётся, Yes → закрывается;
  - скрытый образец кода и пошаговые подсказки;
  - практическая №2 с пустыми и заполненными полями;
  - мини-тест: правильный и неправильный ответ, очки командам;
  - оценивание;
  - сундук: открытие, карточка, сброс;
  - панель T: сумма таймеров 45, выбор ДЗ, «Барлығын тазалау»;
  - видео: нажатие на карточку «Адал азамат» открывает окно, кнопка ▶ запускает ролик через `file://`; без файла показывается подсказка;
  - «Қосу» (12 + 30 = 42, ReadOnly), «Қатені тап» (ответы скрыты до нажатия), мини-флешмоб (5 ситуаций, в том числе быстрые нажатия);
- фото: с `teacher.jpg` оно показывается, без него — заглушка;
- таймер после окончания показывает «Уақыт бітті +00:09», слайд не переключается;
- офлайн: все сетевые запросы заблокированы, презентация работает полностью; страница сама не делает ни одного внешнего запроса.

**Не проверено:** реальный запуск `.bat` в Windows и Microsoft Edge (в среде разработки Windows нет). Пути в `.bat` заключены в кавычки и работают с пробелами и кириллицей. Если `START.bat` не откроет Edge, используйте `OPEN-OFFLINE.bat` или откройте `presentation/index.html` двойным щелчком.
