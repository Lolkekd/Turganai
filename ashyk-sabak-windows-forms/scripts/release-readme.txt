АШЫҚ САБАҚ — «Алғашқы Windows қосымшаларын құру және бағдарлама интерфейсі»
Интерактивная презентация · Каюпова Т.Т. · АЖ-03-24 · 3 курс · 45 минут

КАК ЗАПУСТИТЬ
1. Распакуйте ZIP-архив целиком (например, на Рабочий стол).
2. Дважды щёлкните START.bat — презентация откроется в Microsoft Edge на весь экран.
   Если Edge нет — откроется браузер по умолчанию.
   OPEN-OFFLINE.bat — то же, но в браузере по умолчанию и в обычном окне.
3. Интернет и Node.js НЕ нужны. Интернет нужен только для внешних сайтов
   (Baamboozle, LearningApps, Genially), которые открываются кнопками.

ВИДЕО ИИ (этап «Ұйымдастыру кезеңі»)
Слайд «Адал азамат»: нажмите на карточку ценности — откроется её видео.
Положите файлы в папку presentation\videos\ :
  adal-1.mp4 — «Әділдік пен жауапкершілік»
  adal-2.mp4 — «Заң мен тәртіп»
  adal-3.mp4 — «Еңбекқорлық пен кәсібилік»
  adal-4.mp4 — «Бірлік пен ынтымақ»
Видео ИИ по теме урока: presentation\videos\topic-ai.mp4
(слайд «Енгізу және шығару сұқбаттық терезелері», кнопка «Тақырып бойынша бейнеролик»).
Формат MP4 (H.264). Пока файла нет, в окне показывается подсказка, куда его положить.

ФОТО ПРЕПОДАВАТЕЛЯ
Положите файл teacher.jpg в папку presentation\images\
Фото появится на первом слайде автоматически. Без фото показывается аккуратная заглушка.

УПРАВЛЕНИЕ
  → / ←, PageDown / PageUp   — следующий / предыдущий слайд (подходит пульт-кликер)
  T                         — панель преподавателя (этапы, таймеры, команды, ссылки, ответы, звук, сброс)
  F                         — полноэкранный режим
  Esc                       — закрыть панель
Кнопка «Сабақты бастау» запускает общий таймер урока (его можно остановить кликом).
Таймеры этапов запускаются кнопкой ▶ на слайде. Слайды НЕ переключаются автоматически.

ПЕРЕД НОВЫМ УРОКОМ
Панель преподавателя (T) → «Баптаулар» → «Барлығын тазалау».
Сбрасываются очки, список студентов, таймеры и интерактивы; ссылки и настройки сохраняются.

Состояние (очки, ответы, открытые карточки) хранится в браузере на этом компьютере.
Рекомендуемый браузер: Microsoft Edge или Google Chrome (актуальные версии).
